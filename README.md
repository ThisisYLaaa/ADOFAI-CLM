# 关卡管理器

## 概述

关卡管理器是一个基于Qt的GUI应用程序，用于管理和查看ADOfAI（A Dance of Fire and Ice）关卡文件。该应用程序提供了直观的界面，允许用户浏览关卡信息、设置父文件夹路径、自动重载关卡等功能。

## 项目结构

```
CL/
├── UI/                # GUI相关文件
│   ├── main_window.py     # 主窗口实现
│   ├── settings_window.py # 设置窗口实现
│   └── settings_manager.py # 设置管理实现
├── QTWin11/           # Windows 11风格样式表
│   ├── dark.qss       # 深色模式样式表
│   └── light.qss      # 浅色模式样式表
├── src/               # 核心功能代码
│   ├── func/          # 功能模块
│   └── util/          # 工具模块
├── main.py            # 程序入口
└── settings.yaml      # 设置文件
```

## 使用教程

### 1. 启动程序

运行以下命令启动程序：

```bash
python main.py
```

### 2. 设置父文件夹路径

1. 点击菜单栏中的"设置"选项
2. 在弹出的设置窗口中，点击"浏览"按钮选择ADOfAI关卡文件所在的父文件夹
3. 选择是否在程序启动时自动重载关卡
4. 输入缓存文件名称（可选）
5. 点击"保存"按钮保存设置

### 3. 重载关卡

点击菜单栏中的"重载"选项，程序会重新扫描父文件夹中的关卡文件，并更新关卡列表。

### 4. 查看关卡信息

在关卡列表中，你可以看到每个关卡的详细信息，包括：
- 关卡名称：关卡的标题
- 艺术家：歌曲的艺术家
- 作者：关卡的作者
- 文件名：关卡文件的名称
- 文件路径：关卡文件夹相对于父文件夹的路径

### 5. 打开关卡文件夹

鼠标双击关卡列表中的"文件路径"列，程序会自动打开该关卡所在的文件夹。

### 6. 排序关卡列表

点击表头任意列，关卡列表会按照该列的数据进行排序：
- 第一次点击会按照升序排序
- 再次点击同一列会切换为降序排序
- 点击其他列会按照新列的升序排序
